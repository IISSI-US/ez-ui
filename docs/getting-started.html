Primeros pasos

Tu primera página con ez-ui: HTML, CSS y dos módulos JavaScript, sin compilación.

1. Prepara el proyecto

Copia la biblioteca a ez-ui/, conservando css/, js/, fonts/, icons.svg y sus licencias. Organiza tu aplicación así:

mi-proyecto/
├── index.html
├── main.js
├── app.css
└── ez-ui/
    ├── css/
    ├── js/
    ├── fonts/
    └── icons.svg

Las fuentes están incluidas; puedes personalizarlas con variables CSS. Consulta también variables y temas.

2. Escribe index.html

La estructura y los enlaces son HTML. El botón móvil usa aria-expanded y aria-controls; JavaScript solo cambia su estado. El script clásico del tema se ejecuta en el head, antes de mostrar la página.

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi primera página</title>
  <script src="ez-ui/js/theme-init.js"></script>
  <link rel="stylesheet" href="ez-ui/css/ez-ui.css">
  <link rel="stylesheet" href="app.css">
  <script src="main.js" type="module"></script>
</head>
<body>
  <nav class="ez-navbar" aria-label="Principal">
    <div class="ez-container ez-navbar__inner">
      <a class="ez-navbar__brand" href="index.html">Mi web</a>
      <button class="ez-button ez-button--secondary ez-navbar__toggle"
              type="button" aria-expanded="false" aria-controls="links">Menú</button>
      <ul id="links" class="ez-navbar__links">
        <li><a href="index.html" aria-current="page">Inicio</a></li>
        <li>
          <button id="theme-toggle" class="ez-button ez-button--secondary ez-theme-toggle"
                  type="button" aria-label="Cambiar de tema" title="Cambiar de tema">
            <svg class="ez-icon ez-theme-toggle__moon" aria-hidden="true">
              <use href="ez-ui/icons.svg#moon"></use>
            </svg>
            <svg class="ez-icon ez-theme-toggle__sun" aria-hidden="true">
              <use href="ez-ui/icons.svg#sun"></use>
            </svg>
          </button>
        </li>
      </ul>
    </div>
  </nav>
  <main class="ez-container">
    <h1>Hola, ez-ui</h1>
    <article class="ez-card">
      <div class="ez-card__body">
        <h2>Mi primera tarjeta</h2>
        <p>HTML semántico y estilos reutilizables.</p>
      </div>
    </article>
  </main>
</body>
</html>

3. Activa la interacción

Guarda este módulo como main.js. No construye elementos: conecta los eventos con los nodos HTML ya existentes.

import { ezNavbar } from "./ez-ui/js/navbar.js";
import { ezThemeToggle } from "./ez-ui/js/theme.js";

ezNavbar(document.querySelector(".ez-navbar"));
ezThemeToggle(document.querySelector("#theme-toggle"));

Los módulos type="module" se ejecutan tras analizar el HTML. ezNavbar() despliega el menú en móvil; ezThemeToggle() cambia el tema y guarda la preferencia para la siguiente visita.

4. Prueba y continúa

app.css puede estar vacío: si necesitas estilos propios, añádelos ahí, después de ez-ui.css. Sirve la carpeta mediante un servidor HTTP local (por ejemplo, Live Server de VS Code); no abras el HTML con file://, porque los módulos ES pueden quedar bloqueados.

Comprueba el menú a 375 px, la navegación a 1280 px, el cambio de tema y su persistencia tras recargar. Revisa la consola y la pestaña Red para detectar errores o recursos 404.

Has aprendido: HTML semántico, clases CSS, módulos ES, eventos, atributos ARIA y preferencias de tema. Sigue con Componentes y JavaScript. La reutilización de una barra entre páginas se abordará más adelante.
