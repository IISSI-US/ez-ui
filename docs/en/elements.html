Elements

What has a style without writing any class: texts, images, the keyboard focus and tables. You write semantic HTML and ez-ui gives it its look. The form controls do not need classes either (see Forms).

Texts

Headings, paragraphs and links, with the fonts and colors of ez-ui. The size of h1 and h2 adapts to the width of the screen. code (code) and kbd (a key) use the monospaced font.

Images

An image is never wider than the element that contains it: on a phone it shrinks, and its height changes in proportion, without distorting it. It always has alt, the text that replaces it if it cannot be seen.

Keyboard focus

When you move through the page with the Tab key, the active element is surrounded by an outline of the theme color (:focus-visible), so that you know where you are. With the mouse, it does not appear. Try it: click on the text above the example and then press Tab.

Tables

Tables do not need classes either: they take the whole width, separate the rows with a line and color every other row so that they are easy to follow. The title goes in <caption>, the column headers in <thead> with <th>, and the data in <tbody>. The ez-number class aligns the numbers to the right. If the table may be wider than the screen, it goes inside an ez-scroll, which scrolls it sideways without moving the page; on a narrow screen, its cells do not break the text into several lines.
