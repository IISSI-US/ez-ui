ez-ui

A simple stylesheet for the web projects of IISSI-2: semantic HTML, CSS that can be read from end to end and a few components with JavaScript, without dependencies or a build step.

This page builds a first complete project in a few minutes: a page with a navigation bar, a collapsible menu, a light and dark theme button, and its main color changed. The other pages are the reference of each piece, to look them up when they are needed.

Download

Download ez-ui 1.0.1

The ZIP has an ez-ui/ folder, which is unzipped in the root of the project, next to the project's own folders. ez-ui is not modified: what belongs to the project goes outside its folder. The project looks like this:

ez-ui/VERSION.txt says which version is installed. To update it, the whole ez-ui/ folder is replaced by the one of the new version.

The page

This is the result, in a frame as wide as a phone. Try it: the «Menu» button opens the links, and the theme one switches between the light and the dark theme.

Everything that is seen is in index.html. In its <head>, in this order, go theme-init.js, which applies the saved theme before the page is drawn; the stylesheet of ez-ui and, after it, your own, so that yours wins; and main.js, with type="module" to be able to use import.

The navigation bar and the theme button are explained in JavaScript, and the card, in Components.

Your own stylesheet

The colors of ez-ui are variables: app.css changes the main color, the maroon, for a blue, with a value for each theme. It also adds the style of a class of the project, welcome, with the variables of ez-ui so that it changes with the dark theme.

What else can be changed, and how, is in Customization.

The JavaScript

main.js imports two components of ez-ui and connects them to their elements when the page is loaded. It does not create the bar or the button, which are already in the HTML: it adds what happens when they are clicked.

Opening it with a server

Modules (import) do not work when the file is opened with a double click (file://): the page has to come from an HTTP server. In Visual Studio Code, with the Live Server extension, or from the folder of the project:

and http://localhost:8000/ is opened. If something does not look right, the console of the developer tools shows the errors, and the Network tab, the files that are not found (404): almost always, a mistyped path.

Several pages

With several pages, each one has its navigation bar in the HTML. How not to repeat it is a decision of each application, not of ez-ui: copying it in each page, generating it with templates in the server, or inserting it with JavaScript (fetch) from a common file, as this site does. ez-ui only gives its look (ez-navbar) and its collapsible menu (ezNavbar), which work the same in the three cases. If the bar is inserted with JavaScript, ezNavbar is called afterwards, when it is already in the page.

What comes next

The rest of the site is the reference, a page for each part of ez-ui:

  • Elements: the HTML that has a style without classes, such as texts and tables.
  • Layout: container, gallery and two columns.
  • Components: badges, buttons, alerts, avatars, cards and navigation bars.
  • Forms: fields, help texts and errors.
  • JavaScript: collapsible menu, theme, notifications, loading indicator and dialog.
  • Customization: the names of the classes, the variables, the dark theme, the fonts and the icons, and how to change them.

The examples are from the ez-Soccer Trophy, an invented football league between the schools and faculties of the university.
