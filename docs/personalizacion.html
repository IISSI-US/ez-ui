Personalización de estilos

Adapta ez-ui con CSS nativo, sin editar los archivos de la biblioteca.

La cascada y el orden de carga

Enlaza primero la biblioteca y después tu hoja de aplicación. Si dos reglas tienen el mismo origen, importancia y especificidad, prevalece la última. Una regla más específica puede prevalecer aunque aparezca antes. Las propiedades heredables, como la tipografía, pasan de padres a hijos salvo que estos las redefinan.

<link rel="stylesheet" href="ez-ui/css/ez-ui.css">
<link rel="stylesheet" href="css/app.css">

Evita !important para resolver conflictos normales: comprueba antes el selector y el orden de las reglas.

Variables: personalización global

Las propiedades personalizadas --ez-* se definen en css/tokens.css. Cambiarlas en :root permite que los componentes reutilicen los nuevos valores mediante var(). Los colores del tema oscuro se definen en :root[data-ez-theme="dark"]; si personalizas colores para ambos temas, define también los valores oscuros.

/* css/app.css */
:root {
    --ez-primary: #245b91;
    --ez-space-4: 1.25rem;
}
:root[data-ez-theme="dark"] {
    --ez-primary: #8bc5ff;
}

Una variable también puede definirse en un contenedor para limitar su alcance a sus descendientes.

Una tarjeta, tres alcances

En el HTML, ez-card aporta el estilo de la biblioteca y player-card identifica una tarjeta de la aplicación.

<article class="ez-card player-card">
    <div class="ez-card__body"><h3>Juan Pérez</h3></div>
</article>

Juan Pérez

Para centrar todas las tarjetas, usa .ez-card__body { text-align: center; } en app.css. Para centrar solo las tarjetas de jugadores, usa:

/* css/app.css */
.player-card .ez-card__body {
    text-align: center;
}

Este selector es más específico que .ez-card__body. Un atributo style="text-align: center" sirve para una prueba puntual, pero dificulta reutilizar estilos. Para una utilidad propia reutilizable, crea una clase como .app-text-center { text-align: center; } y aplícala a los elementos que la necesiten.

Tipografía y fuentes

ez-ui incluye archivos WOFF2 locales de Source Sans 3 (normal y cursiva) para el texto y JetBrains Mono para el código. No depende de Google Fonts ni de conexiones externas. css/ez-ui.css importa fonts.css, que declara las familias con @font-face; después font-family selecciona qué familia usar.

WOFF2 es un formato comprimido para la web. Estas fuentes son variables: cada archivo cubre varios pesos. font-display: swap muestra inicialmente una fuente alternativa mientras se carga la principal. Las alternativas del sistema mantienen el texto legible si falla la carga.

En css/tokens.css se definen --ez-font y --ez-font-mono. base.css usa la primera en html, la segunda en code, pre y kbd, y hace que los controles de formulario hereden la fuente. Puedes sustituirlas en tu hoja cargada después de ez-ui:

/* css/app.css */
:root {
    --ez-font: Arial, sans-serif;
    --ez-font-mono: Consolas, monospace;
}

Una fuente propia (opcional)

/* css/app.css */
@font-face {
    font-family: "Mi Fuente";
    src: url("../fonts/mi-fuente.woff2") format("woff2");
    font-display: swap;
}
:root {
    --ez-font: "Mi Fuente", system-ui, sans-serif;
}

La ruta de url(...) es relativa al archivo CSS que la contiene, no al HTML. No edites fonts.css. En las herramientas de desarrollo, inspecciona las fuentes renderizadas en un elemento y la pestaña Red: los WOFF2 deben responder sin errores 404. Al probar el ZIP de distribución, conserva css/ y fonts/ como carpetas hermanas e incluye los archivos OFL-*.txt. Comprueba la carga con el ejemplo servido por HTTP.

El tamaño base actual es 1.0625rem (normalmente 17 px); conviene comprobar su lectura en móvil antes de plantear cambios.
