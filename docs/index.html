ez-ui

Una hoja de estilos sencilla para las prácticas de IISSI-2: HTML semántico, CSS que se puede leer entero y unos pocos componentes con JavaScript, sin dependencias ni compilación.

Esta página monta un primer proyecto completo en unos minutos: una página con barra de navegación, menú plegable, botón de tema claro y oscuro, y el color principal cambiado. Las demás páginas son la referencia de cada pieza, para consultarlas cuando hagan falta.

Descarga

Descargar ez-ui 1.0.0

El ZIP tiene una carpeta ez-ui/, que se descomprime en la raíz del proyecto, junto a las carpetas propias. ez-ui no se modifica: lo del proyecto va fuera de su carpeta. El proyecto queda así:

ez-ui/VERSION.txt dice qué versión está instalada. Para actualizarla, se sustituye la carpeta ez-ui/ entera por la de la versión nueva.

La página

Este es el resultado, en un marco del ancho de un móvil. Pruébalo: el botón «Menú» abre los enlaces, y el de la luna cambia el tema.

Todo lo que se ve está en index.html. En su <head>, por este orden, van theme-init.js, que aplica el tema guardado antes de pintar la página; la hoja de ez-ui y, después, la propia, para que la propia gane; y main.js, con type="module" para poder usar import.

La barra de navegación y el botón de tema se explican en Con JavaScript, y la tarjeta, en Componentes.

La hoja propia

Los colores de ez-ui son variables: app.css cambia el color principal, el granate, por un azul, con un valor para cada tema. También añade el estilo de una clase propia, welcome, con las variables de ez-ui para que cambie con el tema oscuro.

Qué más se puede cambiar, y cómo, está en Personalización.

El JavaScript

main.js importa dos componentes de ez-ui y los conecta a sus elementos cuando la página está cargada. No crea la barra ni el botón, que ya están en el HTML: les añade lo que pasa al pulsarlos.

Abrirla con un servidor

Los módulos (import) no funcionan al abrir el fichero con doble clic (file://): la página tiene que llegar de un servidor HTTP. En Visual Studio Code, con la extensión Live Server, o desde la carpeta del proyecto:

y se abre http://localhost:8000/. Si algo no se ve bien, la consola de las herramientas de desarrollo muestra los errores, y la pestaña Red, los ficheros que no se encuentran (404): casi siempre, una ruta mal escrita.

Y después

El resto de la web es la referencia, una página por cada parte de ez-ui:

  • Personalización: los nombres de las clases, las variables, el tema oscuro y las fuentes, y cómo cambiarlos.
  • Elementos: el HTML que tiene estilo sin clases, como los textos y las tablas.
  • Maquetación: contenedor, galería y dos columnas.
  • Componentes: iconos, etiquetas, botones, alertas, avatares, tarjetas y barras de navegación.
  • Formularios: campos, ayudas y errores.
  • Con JavaScript: menú plegable, tema, notificaciones, indicador de carga y diálogo.

Los ejemplos son del Trofeo ez-Soccer, una liga de fútbol inventada entre las escuelas y facultades de la universidad.
