Fundamentos

Lo que se aplica a toda la página sin escribir ninguna clase: las variables con los colores y las medidas, el tema oscuro, las fuentes y el estilo de los elementos HTML.

Variables

Los colores, las fuentes, los espacios y los radios de las esquinas están en variables CSS, definidas en :root (el elemento <html>), en la hoja tokens.css. El resto de hojas las usan con var(): para cambiar el color principal de toda la biblioteca basta con cambiar una variable.

Las variables se heredan, como el color del texto: si se redefinen en un elemento, cambian solo dentro de él. En este ejemplo, el botón de la derecha está dentro de un <div> que cambia el color principal a verde:

Tema oscuro

El tema oscuro no cambia ninguna regla de los componentes: solo da otros valores a las mismas variables cuando el elemento <html> tiene el atributo data-ez-theme="dark". Pruébalo con el botón «Modo oscuro» de la cabecera.

El botón de esta web cambia el atributo desde JavaScript (document.documentElement.dataset.ezTheme = "dark") y guarda la preferencia en localStorage para la próxima visita.

La preferencia guardada se aplica al cargar cada página con un script clásico en el <head>, no con un módulo. Un script clásico se ejecuta en cuanto el navegador lo lee, antes de pintar nada; un módulo (type="module"), después de leer toda la página. Con un módulo, la página se vería un instante con el tema claro antes de pasar al oscuro.

Fuentes

ez-ui usa Source Sans 3 para el texto y JetBrains Mono para el código. Las dos van en la biblioteca (ez-ui/fonts/), con licencia libre, así que no dependen de ningún servicio externo. @font-face asocia el nombre de cada familia a su fichero; después se usan con font-family como cualquier otra fuente.

Elementos HTML

Los títulos, los párrafos, los enlaces, el código y los controles de formulario tienen estilo sin añadir ninguna clase. Se escribe HTML semántico y ez-ui le da aspecto.

Tablas

Las tablas tampoco necesitan clases: ocupan todo el ancho, separan las filas con una línea y colorean las alternas para seguirlas con la vista. El título va en <caption>, las cabeceras de columna en <thead> con <th>, y los datos en <tbody>. La clase ez-number alinea los números a la derecha.
