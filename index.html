ez-ui

Una hoja de estilos sencilla para las prácticas de IISSI-2: HTML semántico, CSS que se puede leer entero y unos pocos componentes con JavaScript, sin dependencias ni compilación.

Cómo se usa

Se copia la carpeta ez-ui/ al proyecto y se enlaza su hoja principal en el <head> de cada vista:

Los elementos HTML ya tienen estilo sin añadir clases (encabezados, párrafos, enlaces, formularios). Los componentes, como las tarjetas o las alertas, se activan con clases que empiezan por ez-.

Convenciones

Las clases siguen la convención BEM (bloque, elemento y modificador): el nombre de una clase dice a qué componente pertenece y qué papel tiene en él. Todas empiezan por ez-, para distinguirlas de las del proyecto.

Componente

Una clase con el nombre del componente: ez-card, ez-button.

DF

Parte de un componente

El nombre del componente, dos guiones bajos y el de la parte: ez-card__image, ez-card__body, ez-card__footer. Solo tienen sentido dentro de su componente.

Variante

Se añade a la clase del componente, con dos guiones: cambia su aspecto sin repetir el resto (ez-button ez-button--danger).

Variables

Los colores, las fuentes y los espacios son variables que empiezan por --ez-. Se usan con var() en la hoja propia del proyecto, y se pueden cambiar para toda la página o solo dentro de un elemento (ver Fundamentos).

Clases del proyecto

Las clases propias de cada proyecto llevan otro prefijo, o ninguno, para que no se confundan con las de la biblioteca. En un mismo elemento pueden ir juntas.

Cómo ampliar ez-ui

Lo que necesita un proyecto y no está en ez-ui va en una hoja propia, enlazada después de la biblioteca. La biblioteca no se modifica: así se puede actualizar sin perder los cambios, y queda claro qué es de ez-ui y qué es del proyecto.

La hoja propia reutiliza las variables de ez-ui (var(--ez-border), var(--ez-space-4)) para que lo nuevo tenga el mismo aspecto y cambie con el tema oscuro, y usa su propio prefijo para no confundir sus clases con las de la biblioteca.
