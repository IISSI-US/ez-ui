Ejemplos de código

HTML Tarjeta semántica

<article class="ez-card">
  <img class="ez-card__image" src="images/mountain.jpg"
       alt="Paisaje de montaña" width="800" height="600">
  <div class="ez-card__body">
    <h3>Paisaje de montaña</h3>
    <p>Una tarjeta con imagen, título y texto.</p>
    <a class="ez-button" href="#formularios">Ver formulario</a>
  </div>
</article>

CSS Galería y tarjetas

.ez-gallery {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(min(100%, 17rem), 1fr));
  gap: var(--ez-space-6);
}

.ez-card {
  background: var(--ez-surface);
  border: 1px solid var(--ez-border);
  border-radius: var(--ez-radius-lg);
  overflow: hidden;
}

Layout

.ez-gallery distribuye los elementos con Grid. .ez-stack separa los elementos en vertical. El catálogo adapta sus columnas al espacio disponible.

Temas

El botón de la cabecera cambia el tema y recuerda tu preferencia. Los colores se definen en tokens.css y se reutilizan con var().
